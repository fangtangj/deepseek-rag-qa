# 常见问题 FAQ

本文件收集课程学习过程中出现频率最高的问题。提问前请先在此检索，没有答案再联系助教。

## 一、课程安排类

**Q1：课程一共多少课时？**
A：总课时 32 学时，共 8 讲，每讲 4 学时（讲义 2 学时 + 实操 2 学时）。

**Q2：作业什么时候截止？**
A：每讲作业在该讲结束后的第 7 天 23:59 前提交。逾期每 1 天扣该次作业成绩的 10%，超过 3 天按 0 分计。

**Q3：作业可以补交吗？**
A：可以补交，但按逾期规则扣分。特殊情况（病假等）需提前联系助教说明。

**Q4：期末项目什么时候交？**
A：期末项目在全部 8 讲结束后提交，具体日期以课程通知为准。期末项目占总成绩 60%。

**Q5：作业可以几个人一起讨论吗？**
A：可以讨论思路和方法，但代码必须独立完成。发现代码抄袭，当次作业记 0 分。

**Q6：课程的重点讲次是哪几讲？**
A：第 1 讲（线程池）、第 3 讲（MySQL 索引）、第 5 讲（分布式锁）是重点讲次，建议额外安排时间练习。

**Q7：每讲大概需要投入多少时间？**
A：建议每讲投入 4–6 小时，包含看讲义、跟敲代码、完成作业。基础较弱的话预留更多时间。

**Q8：课程资料在哪里获取？**
A：讲义存放在课程资料的 `docs/` 目录，每讲一份 Markdown 文件。示例代码按讲次分支存放，分支名为 `lesson-1`、`lesson-2` 等。

## 二、环境与工具类

**Q9：需要装哪些软件？**
A：JDK 17、IntelliJ IDEA（Community 版即可）、Docker Desktop、DBeaver Community、Git。Maven 不用单独装，IDEA 自带，Spring Boot 工程也会自带 Maven Wrapper（mvnw）。

**Q10：为什么建议用 JDK 17 而不是 JDK 8？**
A：JDK 17 是长期支持版（LTS），也是目前主流 Spring Boot 版本的最低要求。课程讲义里的文本块语法（`""" ... """`）需要 JDK 15 以上才能用。

**Q11：IDEA 里 Maven 该用哪一个？**
A：建议选 IDEA 自带的 `Bundled (Maven 3)`。当 IDEA 使用与自身插件版本不一致的较新 Maven 时，可能报 `Unable to create injector` 之类的错误。命令行用工程自带的 `mvnw` 不受影响。

**Q12：Docker 命令报"无法将 docker 项识别为 cmdlet"怎么办？**
A：这不是没装上，而是当前终端持有的是安装 Docker 之前的 PATH 快照。**把终端完全关掉重新打开**即可，九成情况这样就能解决。

**Q13：`docker ps` 报 `Is the docker daemon running?` 怎么办？**
A：说明 Docker Desktop 没启动。打开 Docker Desktop，等托盘图标显示 `Engine running` 后再重试。注意 `docker` 命令只是客户端，必须依赖 Docker Desktop 这个引擎在运行。

**Q14：拉镜像报 `connection attempt failed` 怎么处理？**
A：这是国内网络访问 Docker Hub 不通。在 Docker Desktop 的 `Settings → Docker Engine` 里配置 `registry-mirrors` 镜像加速地址，点 `Apply & Restart` 后重试。

**Q15：为什么代码里不写 API Key，要用环境变量？**
A：把 Key 硬编码进配置文件再推到 GitHub，等于公开自己的账号额度，仓库里会有机器人扫 `sk-` 开头的字符串。用 `${DEEPSEEK_API_KEY}` 占位、真值放环境变量是标准做法。

**Q16：设了环境变量，为什么 IDEA 里读不到？**
A：环境变量是在 IDEA 启动之后才设置的。必须**完全退出 IDEA 再重新打开**（不是关窗口），IDEA 才会读到新的环境变量。

## 三、技术原理类

**Q17：线程池提交任务后，是先创建非核心线程还是先排队？**
A：**先排队**。执行顺序是：核心线程 → 工作队列 → 非核心线程 → 拒绝策略。只有当队列满了，才会创建超过核心线程数的那部分线程。

**Q18：为什么不能用 `Executors.newFixedThreadPool()`？**
A：它底层用的是无界的 `LinkedBlockingQueue`，任务积压时会无限增长，最终导致 OOM。`newCachedThreadPool()` 的最大线程数是 `Integer.MAX_VALUE`，同样会 OOM。生产环境应直接用 `new ThreadPoolExecutor(...)` 并指定有界队列。

**Q19：Spring Boot 自动装配的入口是什么？**
A：由 `@EnableAutoConfiguration` 触发。它通过 `AutoConfigurationImportSelector` 读取自动配置类清单：Spring Boot 2.7 之前读 `META-INF/spring.factories`；2.7 及以后读 `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports`。

**Q20：为什么我自己定义的 Bean 能覆盖自动配置的默认 Bean？**
A：因为自动配置类上普遍标注了 `@ConditionalOnMissingBean`——只有当容器中不存在该类型的 Bean 时才生效。你定义了，它就让位。

**Q21：为什么 MySQL 索引用 B+ 树而不是 B 树？**
A：B+ 树的非叶子节点只存索引键不存数据，单页能放更多的键，树更矮，磁盘 IO 更少；同时所有数据都在叶子节点且用链表相连，范围查询只要顺序读链表即可。B 树的非叶子节点也存数据，树高更高，范围查询效率更低。

**Q22：什么是回表？怎么避免？**
A：通过二级索引查询时，索引叶子节点只存索引列和主键值，要拿到完整行必须再用主键回聚簇索引查一次，这一步叫回表。避免方法是用**覆盖索引**——让查询涉及的列都包含在索引里，这样直接从索引返回，不需要回表。

**Q23：最左前缀原则是什么？**
A：联合索引 `(a, b, c)` 的排序是先按 a、再按 b、再按 c。所以查询条件必须从最左列开始连续匹配才能用上索引。直接查 b 或 c 用不上索引；范围查询会截断，其后的列只能做过滤。

**Q24：Redis 缓存穿透、击穿、雪崩怎么区分？**
A：穿透是查**数据库里不存在**的数据；击穿是**单个热点 key 过期**导致并发查同一个数据；雪崩是**大批 key 同时过期**或 Redis 本身宕机。

**Q25：缓存一致性为什么推荐"先更新数据库，再删缓存"？**
A：删缓存比更新缓存简单安全；先更新库再删缓存的不一致窗口最小，且即使删除失败也只是残留旧缓存等其自然过期，不会引入新的错误数据。必要时配合延迟双删或 binlog 订阅补偿。

## 四、学习与求职类

**Q26：只会用框架、不懂原理，面试有问题吗？**
A：有。面试官常问"为什么"而不是"是什么"。比如不是问"线程池有几个参数"，而是问"为什么队列优先于非核心线程"。原理答不上来是很明显的减分项。

**Q27：课程内容能写进简历吗？**
A：可以作为项目经历写，但必须是自己真的做过、能讲清楚细节的项目。简历里的每一个数字（如性能提升百分比、并发量）都要能溯源，不能编。

**Q28：面试被问到没准备的问题怎么办？**
A：诚实说明这块了解不深，然后把你**知道的相关知识**说出来。比如被问到不熟悉的分布式一致性协议，可以说你知道的 Redis 分布式锁是怎么保证一致性的。切忌硬编答案。

**Q29：课程答疑接口能问什么？**
A：可以问课程讲义范围内的任何知识点。该接口只依据课程资料回答，如果资料里没有相关内容，它会明确回答"课程资料中没有相关内容"，而不会凭空编造。回答末尾会附上引用的资料文件名。

**Q30：为什么答疑接口有时说"课程资料中没有相关内容"？**
A：这是设计使然。答疑接口被约束为只依据课程资料作答，不启用模型的通用知识。这样做是为了保证答案可溯源，避免模型编造看似正确但与课程内容无关的解释。
